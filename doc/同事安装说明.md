# 工商业储充场站测算工具 — 安装与使用说明

> 本说明面向无编程基础的同事，按步骤操作即可。

---

## 一、准备工作（只需做一次）

### 1. 解压文件

将收到的压缩包解压到固定目录，例如：

```
D:\Station_cost_estimation
```

建议路径尽量简短，避免放在过深的文件夹里。

### 2. 安装 Python（若电脑尚未安装）

1. 打开浏览器访问：https://www.python.org/downloads/
2. 下载 **Python 3.11**（或 3.10–3.12）
3. 运行安装程序
4. **重要**：安装界面底部务必勾选 **「Add python.exe to PATH」**（添加到路径）
5. 点击「Install Now」完成安装

### 3. 首次安装依赖

1. 进入解压后的文件夹
2. **双击** `install.bat`
3. 等待黑色窗口显示「安装完成」（首次约 2–5 分钟，需联网）
4. 按任意键关闭窗口

---

## 二、日常使用

1. **双击** `启动测算工具.bat`
2. 浏览器会自动打开页面（地址一般为 `http://localhost:8501`）
3. 顶部三个页签：**①筛站**（导入 `doc/场站资源摸底收资表.xlsx`，VPP 和配储共用）→ **②评分**（手填峰/时长/空窗，不上传曲线）→ **③精算**（原五步，点「确认测算」）
4. 使用完毕后，**直接关闭黑色命令行窗口**即可停止服务

---

## 三、页面使用简要

| 步骤 | 内容 |
|------|------|
| 第一步 | 场站信息（车位、变压器容量等） |
| 第二步 | 充电桩配置 |
| 第三步 | 储能配置 |
| 第四步 | 施工成本 |
| 第五步 | 运营与测算 |

填写完成后点击 **「项目正向收益及回收期测算」** 或页面内的 **「确认测算」** 按钮。

## 四、常见问题

### 双击 bat 文件没反应或一闪而过

- 可能未安装 Python，或未勾选「Add to PATH」。请重新安装 Python 并勾选该选项。
- 若杀毒软件拦截，请选择「允许运行」。

### 提示「尚未安装依赖」

请先双击 `install.bat` 完成首次安装。

### 浏览器没有自动打开

手动在浏览器地址栏输入：`http://localhost:8501`

### 页面显示「端口被占用」

说明已有另一个测算工具在运行。关闭之前的黑色窗口，或重启电脑后再试。

### 安装依赖很慢或失败

- 确认电脑能访问互联网
- 关闭 VPN 或公司代理后重试
- 重新双击 `install.bat`

### 上传摸底表后页面出现粉红色报错（openpyxl）

这是因为虚拟环境里还没有安装读取 Excel 的库。请**关闭**测算工具窗口，再双击一次 `install.bat`，完成后重新「启动测算工具.bat」。也可以在工具目录执行：

```
venv\Scripts\pip install openpyxl
```

### 如何更新到新版本

1. 用新版本 zip **覆盖**原文件夹中的文件（可保留 `venv` 文件夹）
2. 若更新说明要求重装依赖，再双击一次 `install.bat`
3. 否则直接双击 `启动测算工具.bat` 即可
